What changes between the hosted options?

PathConfigurationWhen the customer clicksFlask creates a Session?
1. Payment Link Stripe Dashboard creates the product, price, and reusable link. Browser -> Stripe Payment Link No
2. Hosted Checkout The app stores a one-time Price ID. Browser -> Flask -> Stripe Checkout -> Browser Yes, one-time payment
3. Hosted subscription The app stores a recurring Price ID. Browser -> Flask -> Stripe Checkout -> Browser Yes, subscription
4. Payment Element The app stores secret/publishable keys and a one-time Price ID. Browser -> Flask (client secret) -> Stripe.js -> Stripe -> Browser Yes, then Stripe.js confirms in-app
5. Embedded Checkout Deferred The app stores a Price ID and creates an embedded Checkout Session. Browser -> Flask (client secret) -> Stripe.js embedded Checkout -> Stripe -> Browser Yes, with Stripe-hosted checkout embedded in-app
6. Payment Element + Payment Intents Deferred The app calculates checkout state and creates a PaymentIntent. Browser -> Flask (PaymentIntent secret) -> Stripe.js -> Stripe -> Browser Yes, lowest-level payment API
